# 界域净化

域卫在「净化之路」上阻击域兽、守住净化水晶与升华水晶的 PvE 防守游戏。

当前版本是**可玩骨架**：一名英雄（三华求御）、一条净化之路、三种域兽、局内成长面板。联机是后续阶段，但代码结构已经为它留好路。

## 运行

```bash
npm install
npm run dev        # http://127.0.0.1:5173
```

生产构建：

```bash
npm run build
npm run preview
```

## 操作

| 按键 | 作用 |
|---|---|
| `WASD` / 方向键 | 移动 |
| 鼠标左键 | 射击 / 确认技能落点 |
| 鼠标右键（长按） | 激光预瞄线；投掷/击退时取消 |
| `R` | 换弹 |
| `Q` | 一技能 · 黑洞雷（再按 Q 退出投掷） |
| `E` | 二技能 · 枪退术 |
| `Tab` | 成长面板（开启时无法攻击，世界继续运行） |
| `空格` | 跳过整备期，提前开下一波（也可直接点 HUD 里的提示） |

## 已实现

- **净化之路**：整张地图就是一条横向通道，右侧裂隙不断涌入域兽，玩家在通道里左右机动防守。三座净化水晶压在通道上，最左端是升华水晶。镜头只做横向滚动（地图高度 = 视口高度）。水晶被拆后没有额外惩罚——**防线直接后退**，下一座水晶暴露在域兽面前。
- **两名可玩域卫**
  - **三华求御（输出）**：三发弹匣、黑洞雷、枪退术、右键预瞄。
  - **陨主（承伤）**：陨盾常驻在正面（挡飞行物、近战减伤），右键短按盾击 / 长按缓慢转向；左键长按预瞄、松开射电磁炮（范围爆炸）；Q 陨石坠（跳起砸地、陷地控制）；E 终极之陨星（碎盾进入强化陨星形态，Q 三连、普攻增伤、一技能变肘击）。
  - 盾牌有毁灭值：正面受击累积，满 100 碎裂并进入陨星形态，用普攻命中可以减少。

### 三华求御
  - 普攻「三发」：3 发弹匣，**弹匣最后一发是穿透激光**，中途换弹不触发。射速偏慢（0.42s 一发），激光有射程（200，屏幕上能看见边界），飞到头就淡出消失。
  - 一技能「黑洞雷」：投掷抛物线 + 落点范围，范围内周期性轻微牵引（一级控制）。
  - 二技能「枪退术」：扇形击退。
  - **右键长按预瞄**：按真实弹道预览，**宽度与激光一致**；瞄准完全自由、不做任何吸附。不穿透的那几发会被第一个挡路的域兽截断（末端画叉），最后一发穿透激光则直达射程末端（末端画双圈）。
- **身份系统**（`shared/types.ts`）：所有实体/弹道/效果可挂 `Tag`（飞行物、范围点、近战攻击…），控制带 `1/2/3` 等级，免控按等级抵消。
  - 目前还没有带免控的域兽，但机制已在自检里验证：给任意域兽设 `immunity.all = 1`，一级牵引即失效；点出「引力增强」升到二级才能拉动。
- **成长面板**：3 条轨道 5 个节点 12 级，局内随时开启、逐级解锁、即时生效。
  - 「特质弹匣 Lv2」是**快速连射两发**（0.085 秒间隔），不是同时出膛。
- **域兽（目前只有普则）**
  - **普则**：进入攻击范围后站定，前方亮起扇形预警，0.8 秒后劈出扇形（会同时命中玩家和水晶）。被击退会打断蓄力。
  - **优先水晶**：域兽一路推进、优先拆水晶。玩家靠得太近会被攻击——**身后/侧面范围小（贴身），正前方挡路范围更大**。
  - **索敌后追击**：一旦锁定玩家就会追，最多离开原位约 130 像素、持续约 2.2 秒；超出范围或玩家倒下就放弃，回到路上继续拆水晶。
- **波次 / 整备 / 结算**：12 波，开局整备 10 秒、波间整备 20 秒（**空格或点击提示可提前开战**），撑过最后一波胜利，升华水晶破碎失败。
- **像素渲染**：480×270 逻辑分辨率整数倍放大，精灵用字符画定义、启动时烘焙，无任何图片资源。

## 结构

```
src/
├─ shared/      类型、数学工具（前后端共用）
├─ content/     英雄 / 域兽 / 波次 / 关卡 / 成长面板的数据
├─ sim/         纯逻辑：World.tick()，无 DOM、无渲染、无网络
├─ render/      Canvas 2D 渲染、精灵烘焙、相机、粒子
├─ ui/          HUD 与成长面板（DOM 叠加层）
├─ main.ts      主循环、输入、流程
└─ simtest.ts   模拟层自检（打开 /test.html 查看）
```

**关键约定**：`sim/` 里不出现 `window`、`document`、`setTimeout`。这样以后把同一份 `sim` 搬到 Node 上跑服务端权威联机时，不需要重写玩法逻辑，只需要换传输层。

## 自检

浏览器打开 `http://127.0.0.1:5173/test.html`，会跑 51 条机制断言（最后一发穿透、免控等级、牵引、引爆、成长面板规则等），结果输出到控制台。

调试用自动演示：`http://127.0.0.1:5173/?bot=1`（可再叠加 `&debug=1` 看玩家坐标等状态）。

## 内容扩展

- 加英雄 / 改数值：`src/content/defs.ts`
- 加成长节点：`GROWTH_NODES` 里加一条数据，并在 `src/sim/growth.ts` 与 `world.ts` 里接上对应效果。
- 加域兽：`ENEMIES` 里加一条，`render/sprites.ts` 加一套精灵，`drawEnemy` 里补一个分支。
